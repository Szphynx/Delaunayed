What it is

The same instrument as Collapse — same grid, same tiles, same two engines, same audio — with the grid lifted into three dimensions so you can see the pattern as an object rather than a chart.

Every control works exactly as it does on the flat device, so use the Collapse manual for the tiles, the engines and the page-by-page control reference. This page only covers what the 3D view adds.

The 3D view

GestureWhat it does
Drag the sceneRotates the stack so you can look along the lanes or down the timeline.
Watch the playheadThe lit row is the step currently sounding; height and colour show which tile sits in each cell.

The cubes are drawn from the live state, so painting on the device below, rolling the dice or collapsing a new pattern all show up in the same frame.
