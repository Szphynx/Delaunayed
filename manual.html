The instruments

Delaunay
Navigable delay · freeze

Delay taps scattered across a plane, each with its own time, pitch, tone and feedback. A playhead blends the three taps around it, so moving through the field morphs the delay instead of switching it. Hold anywhere and it freezes what it is playing.

Collapse
Generative rhythm grid

A grid of steps and lanes you paint with six envelope shapes, played by either a grain engine or a gated delay. It can fill the grid for you under rules it already knows — or learn the rules from a pattern you painted, or from a loop you loaded.

Getting started

Both instruments process audio you give them. Neither makes sound on its own, so the first job is always feeding one.

  1. Tap the page once. Browsers only allow audio to start inside a real interaction. The first tap wakes the engine and loads a short built-in loop so there is something to hear immediately.
  2. Load your own material. Load file accepts WAV, AIFF, MP3 and M4A, and you can drop a file anywhere on the page. Audio in takes a microphone or interface instead. Loop repeats a file rather than playing it once through.
  3. Press ▶ and set Dry/Wet. The dry signal always passes underneath, so this is a balance between source and effect rather than a fade to silence.
  4. Use the canvas. On both instruments the canvas is where the playing happens; the pages underneath are for setting up what the canvas will do.

Both run in a browser with no install. Headphones are worth it — feedback and freeze build up quickly, and the stereo field is where a lot of the detail sits.
