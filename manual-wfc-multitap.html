What it is

The same grid idea as Collapse — steps across time, lanes of audio, six tile types — but here the pattern is solved rather than scattered. Adjacency rules say which tiles may sit next to which, and the solver fills the grid so every neighbour is legal.

  1. Tap once to start audio, then load a file, drop one on the page, or switch on 🎤 Audio In.
  2. Press ▶ to run the sequencer.
  3. Press ⧐ Collapse to solve a new pattern under the current rules.
  4. Paint by hand to pin cells you want kept, then collapse again around them.

Collapsing and painting

⧐ Collapse runs the solver and animates the grid crystallising. ↻ Re-seed throws a fresh random start. Regenerate rebuilds the lane voices underneath.

Learning the rules

This is the part the other devices do not have. Instead of the built-in rule set, the solver can derive its adjacency rules from an example.

ModeLearns fromWhat happens
Hand rulesbuilt-in setThe default musical rules that ship with the device.
Learn ▸ gridwhat you paintedReads every neighbouring pair in the current grid and allows only the pairs it saw. Collapse then generates new patterns in that style.
Learn ▸ audiothe loaded audioSlices the loaded file into steps, measures each slice’s energy and whether it is rising or falling, and maps that onto tiles — so the groove of your sample becomes the rule set.

Paint eight bars of a groove you like, hit Learn ▸ grid, then ⧐ Collapse repeatedly — every result is a different pattern that still belongs to that groove.

Recipes

Teach it your groove

Paint a two-bar rhythm by hand, switch to Learn ▸ grid, then press Collapse a few times. Each pattern is new but sits in the same feel.

Sample-shaped patterns

Load a drum loop, press Learn ▸ audio, then Collapse. The grid follows the loop’s own accents and swells.

Crystallising texture

Grain seq, Grain long, Feedback high, then press Collapse while it plays — you hear the pattern resolve.
