Wave Function Collapse, as a sample slicer. The grid still crystallizes the same way — hit Collapse, or Paint tiles and complete a pattern around them — but every tile now steers a slice-cursor through your loaded sample instead of shaping a grain of whatever's passing through live. The slices themselves aren't equal-width chops: they're cut at the sample's own transients (onset detection, tunable with Onset), so each one is a real event in the file — a hit, a syllable, a pluck. Fwd/Back walk the cursor forward or backward one transient, Hold repeats the current one (a stutter), Leap jumps it to a random one (an accent), Flip plays the current one reversed and throws it hard into the feedback line. Learn ▸ sample reads the loaded file's own envelope and re-weights the rules to match its dynamics. Drop your own file on the Source strip below — the more percussive and varied, the more there is to chop.
