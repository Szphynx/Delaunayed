Tree.

A delay tree grown from six numbers, not a tap list — every branch reads its parent's output, so times, pitches and levels all compound down the tree instead of sitting on a shelf of independent taps.

The idea

A normal multitap delay is a list: six taps, each with its own fixed time, level and pan, all reading the same input. This one is a tree: each tap (a branch) reads the previous tap's output, not the input, so a branch's delay time is really its parent's time plus its own — times compound down the tree the way branches compound on a real plant.

The six numbers on the TREE and TIME pages — Children, Depth, Angle, Trunk, Ratio, Decay — are the whole tree. There is no per-tap editing: change one number and every branch that number touches moves together, which is what a normal delay's tap list can't do.

The turn angle at each branch is also its pitch, snapped to a scale (KEY page), and a wind field (WIND page) can bend the whole tree, which retunes it in real time. That's the other half of the instrument: grow a shape, then let it sway.

Start here

  1. Press ▶. Loads and plays a built-in source (a droning A-minor chord by default) through the tree. Pick a different one, or drop your own file in, from the source strip under the device.
  2. Or play it with notes. The on-screen keyboard (and your computer's a w s e d f t g y h u j k row) feeds the tree a Rhodes-style note instead of a sample — the fastest way to hear exactly what one hit does.
  3. Try a Preset first. Each one is a complete set of all six tree numbers plus a key and a wind setting. Learning the parameters by ear against a preset you already like beats guessing from a blank tree.
  4. Set OUT last. Dry always passes underneath, so Wet only decides how much tree sits on top of it, and Master is the final level over both.

Why is there a gap before the effect?

If you hear the dry hit, then a beat of silence, then the tree — that gap is the Trunk knob, and it's supposed to be there. Nothing else in the signal path adds delay.

The dry signal goes straight from the source to the output with no processing in between — zero added latency. The wet signal goes into the root branch first, and that branch's delay time is exactly Trunk. Not close to Trunk, not Trunk scaled by something — the very first thing you hear from the tree arrives exactly Trunk milliseconds after the dry hit, every time, because that's what Trunk is: the tree's pre-delay.

Decay does not touch this. Decay sets how much quieter each generation gets (branch gain = Decaydepth) — it's a level control, the same job Feedback/Regen does on a normal delay, and it has no say over when anything starts. Turning Decay down makes the tail die out faster and quieter; it will never close the gap between a hit and the first repeat, because timing and level are two separate knobs here on purpose.

Ratio doesn't touch it either — Ratio scales every generation after the root by Ratiodepth, but the root itself is depth 0, and anything to the power of 0 is 1. The root's time is Trunk no matter what Ratio is set to.

So the only knob that moves that gap is Trunk itself, and it now runs down to 2 ms (it used to floor out at 50 ms). That's about as tight as it can get while still being a tree of distinct branches rather than one filtered copy of the input — a real delay pedal has the same wall for the same reason: below a few milliseconds, "delay" and "comb filter" are the same circuit.

Quick test: solo a drum hit, turn Wet to 100% and Dry to 0% on the OUT page, then pull Trunk down while it loops. You'll hear the repeat visibly catch up to the hit as Trunk falls — proof that Trunk is the only thing setting that distance, not Decay.

Controls, and what they'd be called on a normal delay

Every page is at most four knobs. None of them are per-branch — turning one moves the whole tree, which is the trade for not having to program thirty individual taps by hand.

TREE — the shape

ControlRangeWhat it does
PresetFactory / User Loading a patch. Factory Presets are built in; hit SAVE on the transport to snapshot the current tree into User Presets, saved to this browser.
Children1–3 No direct equivalent — closest is a multitap's tap count, except multiplicative. Every branch gets this many children at the next generation, so raising it explodes the total branch count fast: 2 children × Depth 4 is 31 branches, 3 children × the same Depth is 121.
Depth1–5 Like a tape delay's number-of-repeats, except the repeats fan out instead of running in a line. Sets both how long the tail can possibly get (with Trunk/Ratio) and, with Children, the total branch count.
Angle6–60° Not a delay control at all — it's a detune amount, like a chorus or harmonizer's spread. Each turn is also a pitch interval (see Spread, KEY page), so a wide angle means siblings land further apart in pitch, not just in the drawing.

TIME — pre-delay, spacing, decay, tone

ControlRangeWhat it does
Trunk2–700 ms The Time / Pre-delay knob — the root branch's delay time, and the floor on how soon anything wet can arrive. See "Why is there a gap?" above.
Ratio0.4–0.98 How each generation's spacing shrinks from the last (timedepth = Trunk × Ratiodepth, summed down the branch). Close to 1 spreads generations out almost evenly, like a long multitap; low values bunch them up near the front, like a short slapback with a fast flutter behind it.
Decay0.4–0.92 The Feedback / Regen knob, in effect — how much quieter each generation gets (gaindepth = Decaydepth). Unlike real feedback it can't run away: the tree is finite, so this only ever shapes how fast a fixed structure fades, never how long it can ring. For actual self-feeding regeneration, see EXP.
Tone400 Hz–16 kHz The delay's Tone / Damping knob — a lowpass over the wet signal only, after the tree, on the master bus. Rolling it back pushes the tree behind the dry source.

KEY — what pitch a turn means

ControlRangeWhat it does
Scale11 scales Like setting a harmonizer or pitch-quantizer's scale. Every branch's pitch snaps to a degree of this scale — nothing in the tree can land off-key.
Root−12…+12 st The scale's Key control — transposes every branch's pitch together.
Spread2–24 ¢/° How many cents one degree of Angle is worth before snapping to the scale. Works with Angle (TREE page): a wide Angle and a wide Spread push siblings toward opposite ends of the scale; both narrow and every branch stays close to the root's pitch.
Width0–100% The delay's Stereo Width knob — scales how far each branch's pan follows the tree's actual left/right shape. At 0 every branch sits centre; at 100 the pan matches the drawing exactly.

WIND — modulation

ControlRangeWhat it does
Amount0–2 A modulation Depth knob, like a chorus — how far the wind bends the tree. Since a branch's heading is also its pitch and its delay time stretches with the bend, this modulates pitch and time together, not one or the other.
Rate0.02–1.2 Hz The modulation Rate knob, same job as a chorus or tremolo's speed control.
Gust0–100% No direct equivalent — blends a smooth LFO sway toward sudden swelling bursts, more like an envelope-triggered depth than a fixed waveform shape.

Drag the tree on the canvas and your finger becomes the wind directly, like an expression pedal patched into a modulated delay's rate/depth input — Amount/Rate/Gust take back over the instant you let go.

OUT — the mix

ControlRangeWhat it does
Master0–100% Output level over the whole mix, after Dry and Wet are combined — the pedal's final Level knob.
Dry0–100% The unprocessed source. Never removed by Wet — this is a balance, not a crossfade.
Wet0–100% How much tree sits over the dry signal — the delay's Mix knob.

EXP — untested, and off by default

New ideas land here first. Both controls are 0% at every factory preset, and 0% is a true no-op — the tree behaves exactly as if this page didn't exist until you turn one up.

ControlRangeWhat it does
Feedback0–90% An actual Feedback / Regen knob, unlike Decay — a branch's own output re-enters its own delay line, so it can genuinely build and sustain rather than only shaping a fixed fade. Clamped to 0.85 gain per branch and scaled by that branch's own Decay-shaped level, so a deep, quiet branch can't be pushed hotter than a shallow, loud one — but it isn't proven safe at every combination with Decay, so raise it slowly and listen.
Speed0–100% A Wow/Flutter knob — a slow wobble directly on each branch's delay time (not a separate pitch-shift), running faster the deeper the branch. Different from WIND's Amount: this is a fast, continuous per-branch flutter; Wind is a slow sway of the whole tree's shape.

Sounds to try

Tight slapback, not a wash

Start from Still Air (no wind to complicate things). Pull Trunk down to 15–25 ms and Decay down toward 0.5. The repeat sits right on top of the hit instead of trailing behind it — useful for checking Trunk's new low end against the drum-hit case directly.

A chord out of one note

Play a single Rhodes note into Cathedral or Drone Web with Depth at 4-5 and Angle around 30°. Every branch lands on a different scale degree, so one note arrives back as a spread chord.

Storm on a chord

Latch a triad on the keyboard, load the Storm preset, and just listen — Amount and Gust are already high, so the chord's pitches visibly (and audibly) swim as the wind bends the tree.

Careful self-feedback

Any preset, EXP page: bring Feedback up in small steps while Decay stays under 0.7. It's the one control here that hasn't earned full trust yet — that's exactly why it's on its own page.
